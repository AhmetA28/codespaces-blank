U – Understand
- Build a small Python program to manage a library inventory.
- Each book has: id, title, author, genre, available, due_date, checkouts.
- For Tier 2, I need:
  - Level 1: View all available books.
  - Level 2: Search by author or genre (case-insensitive).
  - Level 3: Checkout a book by ID, set due date 2 weeks from today, increment checkouts.

C – Clues
- Starter file library_books.py already gives a list of dictionaries.
- I can import that list and set books = library_books.
- I know how to use:
  - for loops to go through books
  - if conditions to filter by availability
  - .lower() for case-insensitive search
  - datetime.date and timedelta to set due dates
  - input() and print() to interact with the user

A – Assemble (Plan)
1. Import date, timedelta, and library_books.
2. Assign books = library_books.
3. Write view_available_books():
   - Loop through books, print id/title/author if available is True.
4. Write search_books():
   - Ask for search term, make it lowercase.
   - Loop through books, check if term in author.lower() or genre.lower().
   - Print matches with simple status (available or checked out).
5. Write checkout_book():
   - Ask for book id.
   - Find the book with matching id.
   - If already unavailable: print a message.
   - Else:
     - Set available = False.
     - Set due_date = today + 14 days (ISO string).
     - Increase checkouts by 1.
6. Write show_menu() + main():
   - Menu: options 1–4 for view, search, checkout, quit.
   - Use while True loop in main() to handle user choices.

S – Solve
- Translate each step in the plan into real Python functions.
- Keep code simple and use clear print messages.

E – Examine
- Run: python3 library_manager.py
- Test each menu option:
  - View available books.
  - Search with an author and with a genre.
  - Checkout an available book (check due_date and checkouts changed).
  - Try checking out a book that is already checked out to see the error message.
- Fix any mistakes found during testing.
